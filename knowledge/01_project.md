# Demo Community Knowledge Context

## Purpose

This repository ships with a small demo knowledge base so the bot can answer community-specific questions without hardcoding answers in Python.

## Demo Community

- **Name:** Demo Community Hub
- **Focus:** Discord support, announcements, project discussion, and community events
- **Tone:** Helpful, direct, practical, and concise

## Assistant Behavior

- Use this knowledge bank for questions about the demo community.
- Keep Discord answers short and easy to scan.
- Use web search for real organizations, people, recent events, and market data.
- Never invent partnerships, funding, prices, team members, or private information.

## Common Questions

- **What is this bot for?** It helps Discord members get quick answers, search the web, and use community knowledge.
- **Where does community context come from?** Markdown files in the `knowledge/` folder.
- **Can admins update the bot knowledge?** Yes. Edit or add Markdown files, then restart the bot.
