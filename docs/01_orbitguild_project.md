# Project Name: OrbitGuild Labs

## Project Overview

OrbitGuild Labs is a fictional community platform for game creators, indie studios, event hosts, and player groups. It helps communities run quests, answer support questions, publish event schedules, and keep a shared knowledge base for moderators.

## Core Ideas

- **Guild Profiles**: Lightweight community profiles for teams, creators, and player groups.
- **Questline Boards**: Campaign and event tracking for tournaments, playtests, and community missions.
- **Signal Drops**: Announcement workflows for time-sensitive updates.
- **Orbit Credits**: A fictional points system used in examples and demos.
- **PulseScore**: A fictional engagement signal used to explain how the assistant prioritizes community context.

## What The Bot Should Know

- OrbitGuild Labs is fictional and should never claim to be a real company.
- The assistant should help with Discord moderation, event support, quest explanations, and onboarding.
- The assistant should keep answers short, practical, and friendly.
- For current events, prices, or external claims, the assistant should use web search rather than guessing.

## Example FAQ

- **What is OrbitGuild Labs?** A fictional Discord community operations platform for gaming groups.
- **What is Questline?** A fictional campaign system for events, playtests, and community challenges.
- **What are Orbit Credits?** Demo points used for reward examples inside the community.
- **What is PulseScore?** A fictional engagement signal used in sample assistant responses.
- **Is this a real organization?** No. It is placeholder brand content for a demo bot.
